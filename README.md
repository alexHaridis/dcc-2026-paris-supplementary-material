# Rethinking Pretraining for Specialized Design Data: Evidence from the JONES-19 Cultural Design Dataset
This repository provides supplementary material for the paper, A. Haridis and C. Zhou (2026) “Rethinking pretraining for specialized design data: evidence from  the JONES-19 cultural design dataset,” that's published in the Proceedings of the [12th International Conference on  Design Computing and Cognition (DCC ’26)](https://sites.google.com/view/dcc26/), held in Paris, France.
The supplementary material includes the hyperparameters table and additional matrices quantifying the performance of two models, ResNet-18 and ResNet-50, tested on the small-size, cultural image dataset JONES-19. 
See also:
(1) The original publication of the JONES-19 dataset on [the ACM's database](https://dl.acm.org/doi/10.1145/3769526.3769634) and Harvard's open-access [DASH Repository](https://dash.harvard.edu/entities/publication/2e4a2f0a-79d0-42a6-94c5-c14cd586abca).
(2) The JONES-19 image dataset hosted on [HuggingFace](https://huggingface.co/datasets/harvardseas-cultural-ornaments/JONES-19).
